# Security policy

## Reporting a security issue

Do not include credentials, tokens, account identifiers, private data, or exploitable details in a
public issue.

Use GitHub's private vulnerability reporting option on the repository's **Security** tab when it is
available. If a credential is ever committed, revoke or rotate it immediately; deleting it from the
latest revision does not remove it from Git history.

## Current deployment status

This repository currently contains a local ingestion prototype. It is not connected to an AWS
account and does not contain deployed infrastructure or production data.
